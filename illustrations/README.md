# nmoonfox もふもふ高解像度イラスト集

粒状の筆跡を抑え、柔らかな毛並みに揃えたイラスト集です。1枚ずつ独立した透過PNGが5枚と、にっこりするGIFが入っています。

| ファイル | 内容 |
| --- | --- |
| png/01-normal.png | いつものnmoonfox |
| png/02-sleep.png | 三日月のしっぽに包まれてすやすや |
| png/03-look-up.png | 興味しんしんに見上げる |
| png/04-happy.png | なでられてにっこり |
| png/05-soft-blink.png | 目を細める表情 |
| gif/nmoonfox-happy.gif | 通常 → 目を細める → にっこり、のループ |

PNGはすべて1254×1254px、RGBAの背景透過画像です。承認済みのもふもふ参考版を基準に、内蔵imagegenで生成した実寸です。小さなペット用コマの拡大ではありません。通常姿には承認済み参考版をそのまま収録しています。

GIFは768×768px、約3.12秒のループです。水彩の輪郭を保つため淡いラベンダー背景を使用しています。背景を自由に変えたい場合は透過PNGをご利用ください。

ChatGPTペットに登録するスプライトではなく、鑑賞・画像素材用の独立したイラストです。ZIPを展開し、pngフォルダーから好きな画像を開いてください。GIFはブラウザーなどのアニメーション対応アプリで開けます。

preview.jpgは内容を確認するための一覧です。個別画像はpngフォルダーにあります。
promptsフォルダーに生成・修正プロンプト、manifest.jsonに画像寸法とSHA256を保存しています。
