# Publishing conventions

- This repository distributes Moonfox artwork and Japanese installation documentation.
- Keep the shared-pet URL in README.md and INSTALL.md synchronized.
- Public assets only: no local paths, owner-only pet IDs, upload session IDs, temporary signed URLs, or private QA reports.
- v2 is 1536x2288 with 73 frames; v1 is its unmodified top 1536x1872 region with 57 frames.
- Installation claims must distinguish validated Pets-tool registration from untested cross-account adoption and desktop synchronization.
- Do not add or change an artwork license without the owner's instruction.
